1. **Understand the encoding function** in `Task.txt`:

python
```python
   enc = ''.join([chr((ord(flag[i]) << 8) + ord(flag[i + 1])) for i in range(0, len(flag), 2)])
```


This walks through the flag two characters at a time. For each pair `(flag[i], flag[i+1])`, it:


- Shifts the first character's byte value left by 8 bits (`<< 8`)
- Adds the second character's byte value
- Converts that combined 16-bit number back into a single Unicode character with `chr()`


In effect, it's packing two 8-bit ASCII bytes into one 16-bit Unicode codepoint per output character — hence the flag's own hint: *"16 bits instead of 8"*.


1. **Read the `enc` file as UTF-8 text**, not raw bytes — since each "character" now represents 2 original bytes encoded as one Unicode codepoint (values above 255 won't fit in a single byte, so it must have been saved with a multi-byte encoding).
2. **Reverse the transformation** for each character in `enc`:

  - Take its Unicode codepoint with `ord()`
  - Extract the high byte: `codepoint >> 8`
  - Extract the low byte: `codepoint & 0xFF`
  - Convert both back to characters with `chr()` and concatenate them in order
3. **Reassemble** all the recovered byte-pairs in sequence to get the original flag string.


The Python one-liner to do this:

python
```python
with open('enc', 'r', encoding='utf-8') as f:
    data = f.read().strip()

flag = ''.join(chr(ord(ch) >> 8) + chr(ord(ch) & 0xFF) for ch in data)

```
