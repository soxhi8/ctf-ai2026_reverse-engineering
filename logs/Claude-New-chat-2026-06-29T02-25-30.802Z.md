### Complete Solution Write-Up



#### Challenge Summary



This is **picoCTF 2025 — Flag Hunters** (Reverse Engineering). The script implements a tiny domain-specific language (DSL) for playing back song lyrics. The flag is hidden in a `secret_intro` block that appears at the very top of the song data (line 0), but execution always starts at `[VERSE1]`, skipping it entirely.


---


#### Step 1: Understand the Data Layout



The song string is assembled as:


```
Lines 0–3:  secret_intro  ← FLAG IS HERE ("The ether's ours to conquer, picoCTF{...}")
Line  6:    [REFRAIN]
Line 11:    CROWD (Singalong here!);
Line 12:    RETURN                  ← mutable return address
Line 14:    [VERSE1]                ← execution starts HERE
...
```


Since `reader()` is called with `[VERSE1]` as the start label, it jumps straight to line 15, completely skipping the flag at lines 0–3.


---


#### Step 2: Identify the Vulnerability — Semicolon Injection in the DSL



The interpreter processes each line by **splitting on `;`** and evaluating each segment:

python
```python
for line in song_lines[lip].split(';'):
```


When the `CROWD` prompt fires, the user's input is stored like this:

python
```python
crowd = input('Crowd: ')
song_lines[lip] = 'Crowd: ' + crowd   # ← stored back into the live song
lip += 1
```


The key insight: `song_lines[lip]` is now `"Crowd: <your input>"`. On the **next iteration** of the while loop, when `lip` lands back on that line again, it gets split on `;`. So if you inject a semicolon into your input, you smuggle a second command past the `Crowd: ` prefix!


---


#### Step 3: Craft the Exploit Payload



The RETURN command can jump to any line index:

python
```python
elif re.match(r"RETURN [0-9]+", line):
    lip = int(line.split()[1])
```


`RETURN 0` is valid — it sets `lip = 0`, which is the first line of `secret_intro` (the flag).


**The payload:** `A;RETURN 0`


When stored: `song_lines[lip] = "Crowd: A;RETURN 0"`


When re-parsed on the next visit to that line:


- Segment `"Crowd: A"` → printed as plain text (harmless)
- Segment `"RETURN 0"` → matches the regex → `lip = 0` → **jumps to the flag!**

#### Key Takeaway



This challenge demonstrates **DSL injection** — a cousin of SQL injection. When a custom interpreter re-parses user-controlled data, any control character (here `;`) that the user can embed becomes a code injection point. Never re-evaluate user input through an interpreter without strict sanitization.
