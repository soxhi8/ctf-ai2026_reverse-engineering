`bear_sum` starts at `1` and is multiplied by `player.x` every time a bear is found (once per level, 5 levels total). After the final level, `bear_sum` is fed into `GenerateFlagText`, which does a rolling XOR decode:

python
```python
def GenerateFlagText(sum):
    key = sum >> 8
    encoded = "\xd0\xc7...\xb9"   # 33 bytes
    plaintext = [chr(ord(encoded[i]) ^ (key+i)) for i in range(len(encoded))]
    return ''.join(plaintext)
```


So the only unknown is `bear_sum`.


**2. Figure out what `player.x` is when a bear is found**


`hitBear()` triggers when `drill.drill_level == max_drill_level` — i.e., the player drilled all the way to the bottom. The only way to do that without hitting a boulder (`boulder_mode`, a dead end) is to drill in the one column that's guaranteed boulder-free:

python
```python
for i in range(0, tiles_width):
    if (i != len(LevelNames[current_level])):
        boulder_layout.append(random.randint(2, max_drill_level))
    else:
        boulder_layout.append(-1)   # safe column
```


The safe column index is exactly `len(LevelNames[current_level])` — the length of that level's name. So to win each level, the player must move to `x = len(level_name)` and drill straight down.


**3. Note that shuffling doesn't matter**


`random.shuffle(LevelNames)` randomizes level order, but since `bear_sum` is a **product** of all five `x` values across the 5 levels, and each level contributes `x = len(its own name)`, the order is irrelevant — the product is the same regardless of shuffle:
