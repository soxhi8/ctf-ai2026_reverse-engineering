### Concept: Controlling Execution Flow


On x86-64 architecture, when a function is called, the address of the next instruction in the calling function (the return address) is pushed onto the stack. When the function finishes execution (via the `ret` instruction), the CPU pops this address off the stack and jumps to it.

By exploiting a buffer overflow, a practitioner can carefully construct a payload that:

1. Fills the designated buffer space (`0x15` bytes).
2. Fills any alignment padding added by the compiler.
3. Overwrites the saved Base Pointer (RBP) (typically 8 bytes on 64-bit systems).
4. Overwrites the return address with a target address of choice.

In this template, a `win()` function exists at a specific memory address:

```

}
```

If the return address of `vuln()` is overwritten with the memory address of `win()`, the program will execute `win()` instead of returning cleanly to `main()`, triggered when `vuln()` hits its closing brace.
