## Reverse engineering steps



### 1. Look for flag generation



Searching the source reveals an obvious function:


```
def GenerateFlagText(sum):    key = sum >> 8    encoded = "\xd0\xc7\xdf..."    ...
```


This tells us:


- the flag is **not hardcoded**
- it is generated by XORing an encoded string
- the XOR key is derived from `sum >> 8`


---


### 2. Determine where `sum` comes from



Inside `main()`:


```
bear_sum = 1
```


Whenever a bear is found:


```
bear_sum *= player.x
```


At the end of the final level:


```
flag_text = GenerateFlagText(bear_sum)
```


So the only unknown is the final value of `bear_sum`.


---


### 3. Figure out each bear's x-coordinate



The bear is located in the only column **without** a boulder.


During level setup:


```
for i in range(tiles_width):    if (i != len(LevelNames[current_level])):        boulder_layout.append(random.randint(...))    else:        boulder_layout.append(-1)
```


Every column gets a random boulder **except**


```
i == len(LevelNames[current_level])
```


which gets `-1`.


The player reaches the bear only by drilling to the maximum depth in the safe column, so


```
player.x = len(level_name)
```


for every level.

### 4. Level names



```
LevelNames = [    "California",    "Ohio",    "Death Valley",    "Mexico",    "The Grand Canyon"]
```


Their lengths are:


| Level | Length |
| --- | --- |
| California | 10 |
| Ohio | 4 |
| Death Valley | 13 |
| Mexico | 6 |
| The Grand Canyon | 16 |


Although the list is shuffled:


```

```


multiplication is commutative, so the order does not matter.


Therefore


```

### 5. Compute the XOR key



The code uses


```

```

```

### 6. Decode the string



The function performs


```
plaintext[i] = encoded[i] ^ (key + i)
```


Using `key = 180` decodes the ciphertext into:
