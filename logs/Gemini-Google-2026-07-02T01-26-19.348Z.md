<!-- message:assistant -->
## Gemini

The exploitation technique used to bypass **NX (No-eXecute)** is **Return-Oriented Programming (ROP)**.

- **How it works**: Since NX prevents code execution from stack or data segments, ROP works by chaining together existing small snippets of executable code already present in the binary or its linked libraries, known as "gadgets".
- **Application**: By overwriting the saved return address on the stack during a buffer overflow, an attacker can control the execution flow to point to these gadgets, ultimately allowing them to call functions like `system()` to execute arbitrary commands, such as `cat flag.txt`.

Unlike techniques that rely on injecting and executing custom shellcode on the stack—which NX effectively blocks—ROP is specifically designed to work within the constraints of an NX-enabled environment.
